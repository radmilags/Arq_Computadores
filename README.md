## 📚 Descrição

Repositório com os **exercícios e projetos** desenvolvidos na disciplina de **Arquitetura de Computadores**, cursada no **2º período do curso de TADS - 2022.2**.

O conteúdo deste repositório aborda aspectos fundamentais da arquitetura de computadores e lógica de programação de baixo nível utilizando a linguagem **Assembly**.

## 🧠 Tópicos Abordados

- Introdução à linguagem Assembly
- Organização de memória
- Conjunto de instruções (Instruction Set)
- Manipulação de registradores
- Lógica de controle e fluxo
- Programação em baixo nível
- Simuladores e emuladores de Assembly

## ⚙️ Como Executar os Códigos

Para rodar os arquivos `.asm`, recomendamos o uso de simuladores como:

- [MARS (para MIPS)](http://courses.missouristate.edu/kenvollmar/mars/)

### Usando o EMU8086:

1. Baixe e instale o EMU8086.
2. Abra o arquivo `.asm` desejado.
3. Clique em "Compile and Run".
4. Observe a execução passo a passo ou visualize os registradores.

> Certifique-se de que o código está dentro dos padrões da sintaxe suportada pelo seu emulador/simulador.

## 📌 Convenções de Commits

Utilize mensagens de commit padronizadas para facilitar a leitura do histórico:

- `feat:` nova funcionalidade
- `fix:` correção de bugs
- `docs:` alterações na documentação
- `style:` mudanças de formatação, identação, etc
- `refactor:` refatoração de código (sem alterar funcionalidade)
- `test:` adição ou modificação de testes
- `chore:` manutenção e tarefas auxiliares
